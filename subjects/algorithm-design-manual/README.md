# The Algorithm Design Manual

Study material for algorithmic problem solving, data structures, graph algorithms, dynamic programming, and implementation practice.

## Focus Areas

- Algorithm analysis and design patterns
- Data structures
- Sorting and searching
- Graph traversal and graph problems
- Combinatorial search
- Dynamic programming
- Computational geometry and NP-completeness

## Folders

- `notes/`: chapter and topic notes
- `exercises/`: original exercise attempts and postmortems
- `implementations/`: code for algorithms and experiments
